## 🎮 Overview

Project Samurai is an action RPG prototype inspired by the soulslike genre (Dark Souls, Bloodborne) but set in a ** sci-fi universe**. The project demonstrates:

- ⚔️ **Melee Combat System** - Tactical, deliberate combat with positioning and timing
- 📷 **Lock-on Camera** - Dynamic camera system for strategic gameplay
- 🧑‍🎮 **Player & Enemy HUD** - Real-time health, status, and feedback visualization
- 🎨 **Sci-Fi Aesthetics** - Futuristic visuals with custom shaders and effects
- 🔊 **Audio Integration** - Immersive sound design and SFX
- 🏗️ **Modular Architecture** - Clean, expandable code structure for future development

### 📊 Technical Stack

| Component | Technology | Percentage |
|-----------|-----------|-----------|
| Game Logic | C# | 46.8% |

## ✨ Features

### Combat System
- Melee-based tactical combat inspired by soulslike genre
- Deliberate pacing focused on positioning and timing
- Lock-on target system for focused combat
- Dynamic enemy AI behavior

### Camera & Controls
- **Lock-on Camera**: Tracks enemies during combat with smooth transitions
- **Free Camera Mode**: For exploration and navigation
- **Dynamic Framing**: Automatically adjusts for optimal visibility

### User Interface
- **In-Game HUD**: Real-time player and enemy health visualization
- **Main Menu**: Game navigation and settings
- **Pause Menu**: In-game options and controls
- **Visual Feedback**: Damage indicators, status effects, and combat cues

### Audio & Visuals
- Immersive sound effect integration
- Custom sci-fi shader effects
- Futuristic visual aesthetics with neon/dystopian themes
- Particle effects for combat feedback

### Architecture
- Modular gameplay systems for easy expansion
- Clean C# codebase following SOLID principles
- Ready for additional content (enemies, levels, mechanics) Modular and expandable gameplay architecture
